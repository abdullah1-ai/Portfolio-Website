# Personal Portfolio

A modern and responsive personal portfolio website built to showcase my frontend development skills, projects, professional experience, and contact information. The portfolio focuses on clean UI, responsive design, reusable components, and a smooth user experience.

## Features

- Responsive design for different screen sizes
- Modern and interactive user interface
- Hero section with frontend developer introduction
- About section with skills and development approach
- Animated skills section
- Professional experience section
- Featured projects section with live demos and GitHub links
- Contact section
- Currently Available section for internship and junior frontend opportunities
- Smooth animations and transitions
- Reusable React components

## Tech Stack

- React
- JavaScript
- Tailwind CSS
- Vite

## Getting Started

### Clone the repository

```bash
git clone https://github.com/abdullah1-ai/Portfolio-Website.git
```

### Navigate to the project

```bash
cd Portfolio-Website
```

### Install dependencies

```bash
npm install
```

### Start the development server

```bash
npm run dev
```

The application will be available at the local development URL provided by Vite.

## Build for Production

```bash
npm run build
```
